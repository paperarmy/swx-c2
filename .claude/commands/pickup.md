다른 계정이나 이전 세션에서 하던 작업을 이어받는다. 코드를 수정하기 전에:
1. CLAUDE.md와 docs/CURRENT_STATUS.md를 읽어. PRD는 현재 페이즈와 관련된 장만 읽어.
2. git log --oneline -10, git status, git diff로 실제 상태를 확인해.
3. CURRENT_STATUS 내용과 실제 코드가 다르면 그 차이를 먼저 보고해.
4. CURRENT_STATUS 0절(재개 체크리스트) 중 사용자가 할 일이 남아 있으면 먼저 알려줘(예: Supabase 일시정지 해제).
5. 현재 페이즈, 다음 작업 1개, 확인 방법을 5줄 이내로 요약하고 내 승인을 기다려.
